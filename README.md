# Aria Music

支持洛雪自定义音源的多平台网页音乐播放器，内置网易云音乐、QQ 音乐、酷狗音乐和酷我音乐搜索。

## 功能

- 四平台歌曲搜索
- 洛雪自定义音源导入与主备切换
- 音源独立 Worker 运行、超时与自动降级
- 播放失败后自动换源
- 播放、暂停、进度、音量、上一首、下一首
- 播放队列、随机播放和循环播放
- 四平台歌词适配
- 网易云歌单导入
- 收藏、最近播放和浏览器本地持久化
- 响应式桌面及移动端界面
- 跟随系统、亮色和暗色主题切换

## 启动

```bash
npm install
npm run dev
```

打开终端输出的本地地址。搜索无需 API Key；点击右上角“添加音源”，从推荐音源添加一个，或粘贴洛雪音源脚本地址后即可播放。

音源脚本与主备顺序保存在本机 `data/sources.json`，不会发送到第三方服务。音源脚本会在独立 Worker 中运行，但仍建议只导入可信来源。

## 架构

```text
内置搜索适配 -> 歌曲、歌手、专辑和平台原始 ID
音源宿主     -> 调用洛雪音源脚本解析播放地址
歌词适配     -> 独立获取 LRC 歌词
前端播放器   -> 保留现有界面与交互
```

生产运行：

```bash
npm run build
npm start
```
